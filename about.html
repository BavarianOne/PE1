Über PE1

Was ist PE1?

PE1 ist eine moderne Progressive Web App, die als native App auf deinem Gerät installiert werden kann. Sie funktioniert offline, lädt sofort und bietet ein App-ähnliches Erlebnis direkt im Browser.

Technologien

Service Worker für Offline-Caching und Background-Sync.
Web App Manifest für Installierbarkeit und App-Icon.
HTTPS erforderlich für PWA-Features (GitHub Pages bietet das automatisch).

Browser-Unterstützung

Chrome/Edge (Desktop & Android), Firefox, Safari (iOS 16.4+), Samsung Internet. Auf iOS vor 16.4: "Zum Home-Bildschirm" über Share-Menü.

Features

Digitaler Kompass mit Device-Orientation API, GPS-Standort, Kalibrierungserkennung und iOS-Berechtigungs-Handling.
Offline-First durch Service Worker (Cache-First, Stale-While-Revalidate).
Installierbar auf allen Plattformen mit nativem Install-Prompt.

Datenschutz

Keine Tracker, keine Analytics, keine externen Abhängigkeiten außer Google Fonts (Inter, Azeret Mono). Alle Sensordaten bleiben lokal auf deinem Gerät.

Open Source

MIT Lizenz — Code auf GitHub. Beiträge, Issues und Forks sind willkommen!
